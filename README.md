\# SentinelAI — Intelligent Spam \& Threat Detection System



SentinelAI is an NLP and Machine Learning based threat analysis dashboard built with Streamlit. It inspects incoming text messages, emails, and alerts for phishing, deceptive links, and spam patterns.



\## Features

\- TF-IDF Vectorization for n-gram feature extraction.

\- Multinomial Naive Bayes classification with probability metrics.

\- Heuristic checks for embedded URLs and high-urgency social engineering terms.

\- Real-time interactive Streamlit web dashboard.
